⚙️ Configuración inicial
Paso 1 — Google Cloud Console
1. Entrá a console.cloud.google.com
2. Creá un proyecto nuevo
3. Habilitá la API: Google Sheets API y Google Drive API
4. En "Credenciales" → "Crear credenciales" → ID de cliente OAuth 2.0
5. Tipo: Aplicación Web
6. En "Orígenes autorizados" agregá tu dominio (ej: https://tu-sitio.com)
7. Copiá el Client ID
Paso 2 — Google Sheets
1. Creá un Google Sheet nuevo en tu Drive
2. La URL tiene este formato:
docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit
3. Copiá ese Spreadsheet ID
Paso 3 — Editar los archivos
En js/auth.js → reemplazá TU_CLIENT_ID_AQUI

En js/sheets.js → reemplazá TU_SPREADSHEET_ID_AQUI

La primera vez que iniciés sesión, la app crea automáticamente las hojas:
Clientes · Prestamos · Cuotas
Paso 4 — Instalar como app
En Chrome/Edge: buscá el ícono de instalación en la barra de direcciones.
En Android: Menú → "Añadir a pantalla de inicio".
En iOS Safari: Compartir → "Añadir a inicio".
